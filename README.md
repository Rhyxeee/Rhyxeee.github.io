# Rhyxeee Portfolio — Dark Analytics Dashboard Edition

This package is the complete Astro portfolio rebuild with:
- premium dark hero
- glassmorphism header
- 3-row moving tech stack marquee
- improved experience cards
- premium project cards
- proof/focus section
- polished contact and footer

## Local development

```bash
npm install
npm run dev
```

## Deploy
Push to the `main` branch of `Rhyxeee.github.io` and let the included GitHub Actions workflow deploy the site.
